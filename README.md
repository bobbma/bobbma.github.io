# bobbma.github.io

Personal academic website for Yuexiao Ma (马跃萧), designed for direct deployment at <https://bobbma.github.io>.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Deployment

Push the contents of the repository's default branch to the GitHub repository named `bobbma.github.io`. GitHub Pages serves user sites from the repository root.
